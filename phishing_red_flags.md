Phishing Red Flag Checklist

Use this checklist when an email, SMS, QR code, phone call, or other message appears suspicious.

Sender & Identity

- [ ] Display name does not match the actual email address.
- [ ] Sender uses a suspicious or unfamiliar domain.
- [ ] Domain contains spelling mistakes or unusual characters.
- [ ] Reply-To address is different from the expected sender.
- [ ] Message claims to come from an executive, IT team, bank, or trusted organization without proper verification.

Links & Domains

- [ ] Link points to an unexpected website.
- [ ] Domain is a typosquatting or lookalike domain.
- [ ] URL contains a suspicious nested subdomain.
- [ ] The true root domain does not belong to the claimed organization.
- [ ] Link is shortened or hides its destination.
- [ ] QR code asks the user to verify an account, make a payment, or sign in unexpectedly.

Message & Request

- [ ] Message creates unusual urgency.
- [ ] Threatens account closure, penalties, or other negative consequences.
- [ ] Requests passwords, MFA codes, banking information, or other sensitive data.
- [ ] Requests an unusual payment or financial transfer.
- [ ] Asks the user to bypass normal security or approval procedures.
- [ ] Contains an unexpected attachment.

Psychological Triggers

- [ ] Uses authority to pressure the recipient.
- [ ] Uses fear or threats.
- [ ] Uses curiosity to encourage clicking.
- [ ] Offers an unexpected reward or financial benefit.
- [ ] Creates pressure to act before the recipient can verify the request.

Modern Phishing Indicators

- [ ] Unexpected MFA approval requests or repeated MFA prompts.
- [ ] Fake forwarded email chains or unusual timestamps.
- [ ] Callback instructions for a suspicious support number.
- [ ] Fake subscription or payment-failure notices.
- [ ] Unexpected meeting invitations containing login links.
- [ ] Voice or video communication appears to impersonate a trusted person.

Recommended Response

If one or more serious red flags are present:

PAUSE → VERIFY → REPORT

Do not click links, open suspicious attachments, scan unexpected QR codes, provide sensitive information, or call an unverified number.

Triage Outcome

SAFE → Close

SUSPICIOUS → Warn User & Verify

MALICIOUS → Block Domain & Escalate
